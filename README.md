# ModLang — Переводчик модпаков Minecraft

Высокопроизводительный десктопный инструмент для локализации модов, квестов и справочников Minecraft на любой язык.

Написан на **Tauri v2**, **Rust** и **React**.

---

## Возможности

- **Поддержка форматов:**
  - Моды (`.jar`): читает `assets/<mod_id>/lang/en_us.json` и legacy `en_us.lang` (MC 1.12.2 и ниже)
  - Квесты: FTB Quests (`.snbt`), Better Questing (`DefaultQuests.json`)
  - Книги и мануалы: Patchouli (JSON + Markdown), Guide-API
  - Скрипты и конфиги: KubeJS, OpenLoader, Resource Loader
- **Sanitization Engine** — защищает переменные (`%s`, `{0}`), цветовые коды (`§a`, `&c`), теги форматирования (`$(br)`) и единицы измерения (`RF/t`, `FE`, `mB`) от искажения при переводе
- **Несколько движков перевода:**
  - Google Gemini (`gemini-2.5-flash`) с Minecraft-специфичным контекстным промптом
  - OpenAI / OpenRouter — совместим с LM Studio, Ollama, KoboldCPP
  - Google Translate (веб) — многопоточный режим с защитой от блокировок
  - DeepL — Free и Pro тарифы
- **Результат:** генерирует валидные **Resource Pack** и **Datapack** `.zip` с корректным `pack.mcmeta` для Minecraft 1.7.10 — 1.21.1+. Исходные `.jar` файлы не изменяются.
- **Кэш переводов** — уже переведённые строки сохраняются и переиспользуются, что значительно ускоряет повторный перевод модпаков с пересекающимися модами.
- **Интерфейс в стиле Minecraft** — тёмные слоты инвентаря, 3D-кнопки, шкала опыта (XP bar) для отображения прогресса, консоль в виде игрового чата.

## Использование

### Вкладка «Перевод»

Главный экран приложения. Здесь задаются все параметры перевода:

- **Папка инстанса сборки** — укажи путь до папки `minecraft` своего инстанса (PrismLauncher, MultiMC, CurseForge и др.)
- **Целевой язык** — язык, на который будет переведён модпак
- **Версия игры** — нужна для корректного `pack_format` в генерируемом ресурспаке
- **Метод сохранения** — Resource Pack (отдельный `.zip`) или напрямую в файлы (`.jar`/`.snbt`)
- **Объекты перевода** — выбери что переводить: моды, справочники/книги, квесты
- **Движок перевода** — Google Translate, Gemini, OpenAI/OpenRouter или DeepL
- **Режим обработки** — «Доперевод» (пропустить уже переведённые), «Пропуск >90%» или «С нуля»

Кнопка **«Анализ сборки»** — сначала посчитает количество строк и покажет из чего состоит модпак. Кнопка **«Начать перевод»** — запускает перевод, прогресс отображается в игровом чате справа.

### Вкладка «Настройки API»

Настройка ключей и параметров переводчиков:

- **Google Gemini** — API ключ и ID модели
- **OpenAI / OpenRouter / локальная LLM** — эндпоинт и ключ (LM Studio, Ollama и др.)
- **DeepL** — API ключ (Free с суффиксом `:fx` или Pro — определяется автоматически)
- **Google Web** — количество потоков и задержка между запросами
- **Smart Glue** — умная склейка переносов строк для книг Patchouli

Настройки сохраняются кнопкой **«Сохранить настройки»** и хранятся локально.

### Вкладка «Глоссарий и Кэш»

Управление кэшем переводов. Кэш автоматически пополняется при каждом переводе — повторные запросы к API не делаются.

**Где получить API ключи:**
- Gemini: [aistudio.google.com](https://aistudio.google.com) — есть бесплатный лимит
- DeepL: [deepl.com/pro-api](https://www.deepl.com/pro-api) — Free: 500 000 символов в месяц
- OpenRouter: [openrouter.ai](https://openrouter.ai) — много бесплатных моделей

## Готовый кэш переводов

`modlang_cache_export.zip` содержит базу кэша из **более 300 000+** уже переведённых строк из сотен популярных Minecraft-модов. Названия предметов, подсказки, интерфейс — они повторяются от сборки к сборке, и с этим кэшем ModLang мгновенно берёт готовый результат без траты времени и токенов.

**Как использовать:**
1. Распакуй `modlang_cache_export.zip` (внутри будет файл `modlang_cache_export.json`)
2. Открой вкладку **«Глоссарий и Кэш»** в приложении
3. Нажми кнопку **«Импорт кэша из JSON»** и выбери распакованный `modlang_cache_export.json`

## Сборка из исходников

**Требования:**
- [Node.js](https://nodejs.org/) v18+
- [Rust и Cargo](https://rustup.rs/) v1.75+

```bash
# Установить зависимости фронтенда
npm install

# Запуск в режиме разработки
npm run tauri dev

# Сборка релизной версии
npm run tauri build
```
